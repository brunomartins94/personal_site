06 — LABORATÓRIO DE DADOS

Dez aplicações curtas para aprofundar a prática.

Cada aplicação tem um problema delimitado, uma forma simples de execução e ao menos uma evidência técnica: teste, métrica, decisão documentada ou demonstração. Em conjunto, elas ampliam o portfólio de fundamentos a cloud e observabilidade.

  1. 01

    API → S3 Data Landing

    Ingestão incremental de API pública com Python, paginação, logs e arquivos JSON versionados no S3.

    Python · AWS S3 · IAM
  2. 02

    CSV para Parquet Particionado

    Conversor com validação de esquema e comparação simples de tamanho e tempo de consulta.

    Python · Parquet · DuckDB
  3. 03

    Modelo Analítico de Vendas

    Schema estrela com fatos e dimensões, queries de negócio e decisões de modelagem documentadas.

    SQL · PostgreSQL · Data modeling
  4. 04

    dbt Trust Layer

    Modelos staging e marts, testes de unicidade e relacionamento, documentação e lineage.

    dbt · SQL · Data quality
  5. 05

    Airflow Retry Lab

    DAG idempotente com dependências, retry, backfill e alerta controlado de falha.

    Apache Airflow · Docker
  6. 06

    Glue + Athena Lake Query

    Catalogação de dados no S3 e consultas serverless sobre uma camada de dados particionada.

    AWS Glue · Athena · S3
  7. 07

    Redshift Warehouse Load

    Carga de Parquet do S3, tabela de consumo e uma decisão de distribuição e ordenação explicada.

    Amazon Redshift · S3 · SQL
  8. 08

    Event Stream Mini Platform

    Geração, consumo e deduplicação de eventos de aplicações, com evento atrasado como caso de teste.

    Kinesis ou Kafka · Python
  9. 09

    Infra as Code de um Pipeline

    Bucket, permissões mínimas e recursos de processamento provisionados e revisáveis por código.

    Terraform · AWS IAM · S3
  10. 10

    Data Pipeline Health Check

    Métricas de freshness, volume e falhas com alerta e painel operacional enxuto.

    CloudWatch · dbt tests · Observability
